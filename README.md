# 盖章统计小程序

## 项目简介

这是一个用于记录和统计学生签章信息的微信小程序。主要功能包括签章登记和数据导出。

## 主要功能

### 1. 首页
- 白色背景界面
- 两个功能按钮:
  - **签章登记** - 进入信息填写页面
  - **数据导出** - 进入数据导出页面
- 按钮默认颜色:`#587558`
- 按钮点击时变为:`#FFB414`

### 2. 签章登记
填写内容包括:
- **签章资料持有人姓名** - 文本输入
- **签章资料持有人一卡通号** - 文本输入
- **签章资料名称** - 下拉选择(就业协议书/就业推荐表)

功能特点:
- 提交前会检查该类型的数据库中是否存在重复记录
- 如果姓名重复,提示"XX库已存在该签章资料持有人,请重新提交"
- 如果一卡通号重复,提示"XX库已存在签章资料持有人一卡通号,请重新提交"
- 提交成功后显示提交的详细信息

### 3. 数据导出
- 需要账号密码验证
  - 账号: `splzl123`
  - 密码: `SPl25924512`
- 登录后可以:
  - 查看各类型数据的统计数量
  - 导出就业协议书数据
  - 导出就业推荐表数据
  - 导出所有数据
- 数据以CSV格式导出,可在Excel中打开

## 数据存储

小程序使用微信本地存储(Storage)来保存数据:
- `agreementData` - 存储就业协议书记录
- `registrationData` - 存储就业推荐表记录

每条记录包含:
- 姓名
- 一卡通号
- 资料类型
- 提交时间

## 使用说明

### 开发环境
1. 下载并安装[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 在微信开发者工具中导入本项目
3. 选择"小程序"项目类型
4. AppID可以选择"测试号"进行开发调试

### 部署上线
1. 在微信公众平台注册小程序账号
2. 在`project.config.json`中配置正确的AppID
3. 在微信开发者工具中点击"上传"
4. 在微信公众平台提交审核

## 注意事项

1. 数据存储在用户本地,卸载小程序后数据会丢失
2. 每个用户的数据是独立的,不同用户之间数据不共享
3. 如需多用户共享数据,需要配置后端服务器
4. CSV导出功能在部分设备上可能需要用户手动保存文件
